> **Welcome to the definitive Spring AI enterprise course in Java.**  
> Built from the ground up using **Spec-Driven Development (SDD)**, this curriculum takes you from absolute beginner to building production-grade autonomous agent systems, multi-modal workflows, enterprise RAG, and MCP microservices.

---

## 🌟 Key Course Features

- 🚀 **Modern Tech Stack**: Java 27 (LTS), Spring Boot 4.0, Spring AI Fluent API, Virtual Threads.
- 💰 **Zero-Cost Developer Experience**: Run 100% of the course locally using **Ollama** and **Docker Compose / Testcontainers** without paid cloud API keys.
- 🇹🇷 / 🇬🇧 **Bilingual Courseware**: Every single module includes complete lesson notes and PDF handbooks in both **English** and **Türkçe**.
- 🛠️ **Spec-Driven Development (SDD)**: Built following Addy Osmani's SDD principles: every module has a formal specification (`.spec.md`), architectural plan (`.plan.md`), and granular tasks (`.todo.md`).
- 📚 **Hands-on Homework & Automated Grading**: Each module includes a `homework/starter` project with failing tests and a verified `homework/solution`.
- 🏆 **Enterprise Capstone Project**: Build a complete, production-ready **Intelligent Knowledge & Operations Platform** with RAG, Tool Execution, ReAct Multi-Agents, and OpenTelemetry observability.

## ⚡ Quick Start: 3 Steps to Run Locally

### 1. Start Local AI & Database Infrastructure
```bash
docker compose up -d
./scripts/setup-local-ollama.sh
```

### 2. Build the Complete Course Reactor
```bash
mvn clean install -DskipTests
```

### 3. Run Any Module
```bash
# Run Module 01 with local Ollama profile
mvn -pl module-01-foundations-and-models spring-boot:run

# Or run tests offline with zero external dependencies
mvn test -Dspring.profiles.active=test
```
