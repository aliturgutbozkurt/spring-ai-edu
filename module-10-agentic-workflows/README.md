# Module 10: Agentic AI & Autonomous Multi-Agent Workflows

Welcome to **Module 10** of the Spring AI Educational Series. This module teaches you how to construct autonomous, agentic reasoning loops and multi-agent coordination architectures in Java.

## Key Features
- **ReAct Feedback Loops**: Autonomous Thought -> Action -> Observation execution engines.
- **Supervisor-Worker Squads**: Task planning, dynamic sub-goal delegation, and result synthesis.
- **Operational Guardrails**: Max iteration enforcement and loop detection.
- **Human-in-the-Loop Validation**: Approval checkpoints for destructive operations.
- **Bilingual Documentation & Marp Slides**: Fully compiled PDF notes in English and Turkish.

```bash
mvn clean test -pl module-10-agentic-workflows -am
```
